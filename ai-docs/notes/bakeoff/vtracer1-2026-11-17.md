Presets bw fail every colour image (one colour). --simplify 1.5 leaves self-intersections on line and photo.

Findings:
- 1.0 default output matches 0.6.15 (same node, path and colour counts and overlap on all four colour images): no gain from upgrading alone. 1.0 runs ~10x faster as a CLI (0.02-0.1 s vs 0.3-0.5 s through the Python subprocess).
- Win by measurement: photo with `--preset poster` (+0.044 overlap, still inside the photo node budget). Wired as opt-in `trace --backend vtracer1` (PHW_VTRACER or vtracer 1.x on PATH), not the auto default, because 1.0 is an alpha prebuilt binary and not pip-installable. Test: tests/test_phw4.py `test_vtracer1_backend`.
- Sprite: 1.0 pixel mode uses 29% fewer nodes than the own pixel-exact tracer at the same exact overlap; not wired (pixel kind always uses the own tracer; 20 paths vs one per colour). Candidate follow-up.
- The own tracer still wins logo, icon and line on both overlap and nodes.
